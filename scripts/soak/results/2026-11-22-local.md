# Short local soak with the server's own flushing (2026-11-22)

- **What:** `scripts/soak/soak.py --smoke --duration 180 --flush-every 0
  --compact-every 0 --visible-every 2 --run-id local-20261122`. This is the
  smoke workload for 3 minutes instead of 5. The driver neither flushes nor
  compacts, so documents become visible to `eventual` reads only through
  the server's own idle flush (`KOSHA_FLUSH_MAX_AGE_MS`, default 1000 ms)
  and size flush (`KOSHA_FLUSH_THRESHOLD`, default 1000). The CI smoke turns
  the idle flush off and flushes from the driver every 2 s instead.
- **Commit:** `e174058` (main, the PR #426 merge), with no local changes.
  `cargo build --release -p kosha-server --no-default-features`.
- **Date:** 2026-11-22.
- **Setup:** one standalone server (no S3, local WAL, in-memory control
  plane) on an Apple M5 laptop, with the driver on the same machine. Every
  setting was left at its default. Writes and queries went to the same pod,
  so this does not cover the cross-pod path (manifest poll).
- **Full report:** [`2026-11-22-local.json`](2026-11-22-local.json).
